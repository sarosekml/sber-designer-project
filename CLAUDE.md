# CLAUDE.md

Инструкции по разработке этого репозитория живут в
[`AGENTS.md`](./AGENTS.md). Прочитай его перед любым изменением. Этот файл
существует только потому, что Claude Code ищет имя `CLAUDE.md`; отдельных
правил здесь нет.

Подробности:

- `AGENTS.md` — правила разработки (канон)
- `.agents/` — кит агентов-разработчиков (скиллы, роли, чеклисты)
- `packages/agent-kit/kit/` — продуктовый agent kit встроенного
  `ai-product-designer` (product data, не инструкции по разработке; ADR-0020)
- `docs/architecture/adr/` — архитектурные решения
- `docs/how-it-works/code-map.md` — карта модулей
