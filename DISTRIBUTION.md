# Distribution

Этот репозиторий — разовая выдача sber-designer команде для аудита,
тестирования и дальнейшего развития. Срез односторонний: изменения из исходного
репозитория сюда не накатываются, и эта копия развивается независимо.

История исходного репозитория не перенесена: первый коммит этого репозитория —
начало его собственной истории. Версию, время сборки, commit и автора показывает
**Settings → About** (данные из `GET /api/version`, метку пишет
`bun run build:info`).

## С чего начать

- [`README.md`](README.md) — обзор продукта;
- [`QUICKSTART.md`](QUICKSTART.md) — команды запуска и проверок;
- [`AGENTS.md`](AGENTS.md) и [`.agents/`](.agents/README.md) — правила для
  coding agents (Claude Code читает их через [`CLAUDE.md`](CLAUDE.md));
- [`docs/how-it-works/`](docs/how-it-works/README.md) — как устроена система
  сейчас;
- [`docs/architecture/adr/`](docs/architecture/adr/README.md) — почему она
  устроена именно так;
- [`projects/`](projects) — демо-проекты для ручной проверки: React +
  Storybook (`demo-project`), HTML-first (`demo-html-project`) и UI-kit
  (`ibp-ui-kit`). Зависимости в них не закоммичены — ставятся их собственным
  пакетным менеджером. Корневые `bun run test`, `bun run lint` и Prettier их не
  трогают.

## Что сознательно не передано

- журнал задач, ревью, live-прогоны, черновики идей и планы разработки;
- видение продукта и дорожные карты;
- инвентарь репозитория и гейты, которые проверяли этот журнал
  (`repo:check`, `repo:inventory`, генерация индекса задач);
- конфигурация личных инструментов автора (внешние MCP-серверы, настройки
  агентов на его машине);
- локальные файлы окружения: `.env`, `sber-designer.local.json`, сборки,
  кэши, логи;
- в демо-проектах — история чатов ассистента, журналы прогонов агента,
  накопленная style memory, вложенные git-репозитории и git-хуки.

ADR сохранены целиком. Где они ссылались на задачи разработки, ссылка снята, а
номер задачи оставлен текстом как указание на происхождение решения.
